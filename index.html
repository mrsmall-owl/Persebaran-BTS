🧹 Cleaning Data BTS

Proses pembersihan data mentah BTS sebelum digunakan untuk analisis spasial.

Langkah Cleaning
1
Hapus Duplikat
Identifikasi dan hapus baris data BTS yang memiliki nama atau koordinat sama. Total duplikat ditemukan: 0 dari 25 record.
✓ Selesai
2
Isi Nilai Kosong (Null/Missing)
Field yang kosong diisi dengan nilai default: status → "Tidak Diketahui", ketinggian → rata-rata wilayah. Null ditemukan: 0.
✓ Selesai
3
Standarisasi Nama Operator
Normalisasi variasi nama: "Telkomsel / TSEL / telkomsel" → "Telkomsel". Semua operator sudah seragam: Telkomsel, Indosat, XL Axiata, Tri.
✓ Selesai
4
Validasi Tipe Data
Pastikan lat/lng bertipe float, ketinggian integer, tahun integer (4 digit). Field teks sudah di-trim dari spasi berlebih.
✓ Selesai
5
Normalisasi Tipe Jaringan
Unifikasi label jaringan: "LTE" → "4G", "UMTS" → "3G", "GSM" → "2G", "NR" → "5G".
✓ Selesai
